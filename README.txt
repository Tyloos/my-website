PATCH GIẢM GIẬT KHI CHUYỂN TRANG

Copy thư mục assets trong patch vào thư mục gốc website và chọn Replace/Overwrite.

Các file được cập nhật:
- assets/js/common.js
- assets/js/page-effects.js
- assets/js/about.js
- assets/css/shared.css
- assets/css/page-effects.css
- assets/css/about.css
- assets/css/certificates.css
- assets/css/news.css

Sau khi copy:
1. Stop Live Server.
2. Open with Live Server lại từ index.html.
3. Nhấn Ctrl + F5.
